Drop royalty-free music tracks here (mp3/wav/m4a/ogg/flac) and set `video.music.dir: music`
(or `/app/music` in Docker). Name files after their mood — e.g. `curious-awe-ambient.mp3`,
`tense-build.mp3` — and the editor picks the track whose name matches the script's `music_mood`.
Only use music you have the rights to publish.
